# Dorton AI

Dorton AI is an AI-powered assistant project focused on backend services for authentication, chat, document handling, image processing, and smart search.

## Current Status
- Backend initial setup completed
- Core project structure created under Backend
- Authentication, chat, document, and image modules are being developed
- AI and file-processing services are integrated for future features

## Tech Stack
- Node.js + Express
- MongoDB + Mongoose
- JWT, bcrypt, cookie-parser
- Socket.IO for real-time communication
- OpenAI / Google AI / LangChain integrations
- Multer, PDF, and document processing support

## 8-Day Plan
1. Day 1: Project README and setup

4. Day 4: Chat core features
5. Day 5: Document upload and processing
6. Day 6: Image and file services
